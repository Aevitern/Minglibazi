# 苍燃九宫盲派 · 八字断命（公开协作版）

把七份苍燃九宫盲派资料蒸馏成 **26 册可检索分册 + 一个纯标准库排盘器** 的 WorkBuddy Skill。

**性质**：传统命理文献的整理与检索工具，不主张任何预测效力。

## 能做什么

- 排四柱、定时辰、起大运。两种时辰口径：盲派双数整点分时辰（默认）、通行法 `--shichen standard`
- 定格、判真假、论局、取象、断应期；每条断语可回溯到原书页标
- 查 442 条口诀、103 例断案、120 例八格取法、何知章十论 136 条、小儿关煞 054 条等语料
- 按本门次序输出：「16 定名 → 03 判真 → 14 论局 → 12 措辞」

## 不做什么

- 不替代医疗、法律、投资、婚恋决策
- 不断生死、不断他人品行、不断胎儿性别（09 册 §3、§5 为硬边界）
- 不用于收费欺诈与歧视性决策

## 安装

把整个目录拷到下面任一位置，重启 WorkBuddy 或新开对话即可。入口是 `SKILL.md`。

- 用户级（所有项目可用）：`~/.workbuddy/skills/cangran-jiugong-mangpai/`
- 项目级（仅当前项目）：`<项目>/.workbuddy/skills/cangran-jiugong-mangpai/`

排盘器只需 Python 3，无第三方依赖：

```
python scripts/paipan.py 2002-11-21 08:00 --gender 男 --shichen standard
python scripts/paipan.py 2002-11-21 08:00 --gender 男 --shichen standard --json
```

## A / B / C 三层

- **A 类**：可作断命法则与旁证的条文
- **B 类**：旧时江湖营业话术、条口、临场套话（22 册 §2.2 等），作者自陈「条口任意选一句都会准」——**只作文献保存，不得据此下断语**
- **C 类**：测字、手相、脉象、符咒、内丹、八面金全册（25 册）——**非八字，不作断命依据**

九项新旧口径冲突（用神扶抑、旺衰五气、格局生死、三刑第四套、合化提纲、桃花取法等）**一律以 00–17 册判据为准**，详见 `SKILL.md`「第五个口径分歧」。
