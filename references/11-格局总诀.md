## §1　取格四总则

### 1.1　四条原文

> **(一) 月支本气透于天干**（如寅月透甲，卯月透乙，辰月透戌（疑为「戊」），巳月透丙，午月透丁，未月透己，申月透庚，酉月透辛，戌月透亥（疑为「戊」），亥月透壬）。[总诀 八格(一)]

> **(二) 干上未透月支本气，而透月支所藏之神，即以该神取为格局**（如寅月未透甲木于干上，而透丙或透戊，则可取丙或戊为格）。若支藏两神，并透干上，则斟酌其一（**以有力而无克合者为上**）。[总诀 八格(二)]

> **(三) 月支本气未透，月内所藏之神，亦不透，以月内人元，轻重较量，择一有力而无克合者为格。**[总诀 八格(三)]

> **(四) 比劫不能取格，禄刃非在八格之内。**[总诀 八格(四)]

### 1.2　逐则分解

| 序 | 条件 | 结论 | 备注 |
|---|---|---|---|
| 一 | 月支**本气**透干 | 取本气之十神为格 | 本条最硬，优先于二、三 |
| 二 | 本气不透，月支**所藏他神**透干 | 取该透出之神为格 | 若藏两神并透 → **择"有力而无克合者"，不按本气／中气／余气排序** |
| 三 | 本气与他藏**皆不透** | 于月支人元中"轻重较量"，择一有力无克合者为格 | 注意：**不是固定取本气** |
| 四 | 比肩、劫财 | 不能取格 | — |
| 四 | 建禄（日禄在月支）、月刃 | **不入八格**，归变格（§3.2） | 与 03 册把归禄／阳刃列为第 7、8 格不同，见 §5 |

### 1.3　三个隐含前提（原文未明说，但从 120 例可反推）

**前提一：只用"透干"作判据，不用"司令"。**
全表 120 例，无一条提到节气深浅、司令、司命。凡月支本气透干即取本气，不问生于该月第几日。**这是本册与盲派最根本的分歧**（§5-①）。

**前提二：月支只取本气与所藏，不论会合改属性。**
表内从无"月支因三合三会而变五行"之例，而 03 册 §2.2 第四条明列此条。本册缺此一路（§5-⑩）。

**前提三："有力而无克合"是唯一的质量判据。**
原文三处用同一句话（(二)(三) 各一次，及"择一有力而无克合者"），意思是：**透出的干要本身有根有势，且不被克制、不被合去**。这一条与 03 册"透出才得力，却怕埋藏暗有根"同旨，可互参。

## §2　八格取法全表（120 例）

### 2.1　读法

下表把原文 120 例（10 日干 × 12 月支）逐条拆开，一行一支。三列含义：

| 列 | 含义 |
|---|---|
| **月支** | 出生月支 |
| **干透何神 → 取何格** | 按 §1 总则，天干透出该字时取该格；一支多行的，逐条列出（可兼取两三格） |
| **诸干皆不透时** | 原文对每个月的交代，分两种：<br>· **「不透亦可取」**——该月支只藏一字，本气独透与否都取此格<br>· **「酌取其一」**——该月支藏两三字，原文作"若 X、Y 皆不透，亦可酌取其一"，即于人元中较量取一 |

**加粗的月支**为禄、刃位，原文断为「非八格」，须转 §3.2 建禄格／月刃格看。

## §3　变格之法

### 3.1　变格优先于正格

> 八字取格局，若适合变格，就应先取变格为格局，如果不合变格，或变格不真，破格，再以正格论之。变格即是特别格局，一般分为下列数种：(一)建禄格月刃格。(二)专旺格。(三)从格。(四)化气格。(五)半壁格。[总诀 变格]

**这是本册最重要的一条次序令**：见到禄刃、专旺、从、化气、半壁之象，**先按变格验条件**；不合或不合真、已破，才退回八格。次序颠倒会得出完全相反的用神——例如把真从财格误作"财多身弱"的正格，用神会从财星改成印比，吉凶全反。

### 3.2　建禄格·月刃格（禄刃格）

> 月支为日干之禄或羊刃者，即可取为建禄格，或月刃格，**惟阴干无月刃格**。[总诀 变格(一)]

| 日干 | 禄（建禄格） | 刃（月刃格） |
|---|---|---|
| 甲 | 寅 | 卯 |
| 乙 | 卯 | 阴干无刃 |
| 丙 | 巳 | 午（**原文此月仍取伤官格**，见 §6-3） |
| 丁 | 午 | 阴干无刃 |
| 戊 | 巳 | 午（**原文此月仍取正印格**，见 §6-3） |
| 己 | 午 | 阴干无刃 |
| 庚 | 申 | 酉 |
| 辛 | 酉 | 阴干无刃 |
| 壬 | 亥 | 子 |
| 癸 | 子 | 阴干无刃 |

**R11-1**　月支为日干之禄 → 建禄格；月支为阳干之刃 → 月刃格；阴干不立月刃格。[总诀 变格(一)]

> **版本注**：原文对禄刃格本身未给喜忌，只说"即可取为建禄格或月刃格"。禄刃格的吉凶须回 03 册 §5.9（阳刃格）与 §7（归禄）看，本册不补。

### 3.3　专旺格（一行得气格）

#### 3.3.1　总则

> 专旺格，或名为一行得气格。当八字日主五行极端强旺，当令得时，此命造即可以专旺格论之。……专旺格成时，**最喜格中有食伤来流通其气**，如此方可源远流长，富贵绵绵。同时**专旺之五行，必须透干格为最真**。[总诀 变格(二)]

| 条件 | 结论 |
|---|---|
| 日主五行极端强旺、当令得时 | 可论专旺格 |
| 旺神**透干** | 为真；不透则不真 |
| 格中有**食伤**流通其气 | 最喜，主富贵绵绵、源远流长 |
| 见**官杀** | **破格** → 退回正格论 |
| 见**财星**逆损旺气 | **破格** → 退回正格论；**惟财只一粒、虚浮天干无根，可作"微破"论，仍算专旺** |
| 运行**官杀** | 破败、凶灾、疾厄、意外、刑伤 |
| 月支逢**岁运冲克** | 破财、是非、困厄、灾伤 |
| **原局**月支逢他支冲 | 一生多波折、多冲击、奔波出外、多阻难 |

#### 3.3.3　从强格、从旺格（与专旺最易混）

> 从强格、从旺格与专旺格即为相似，即八字日主亦极强旺，日主当令，局中印星比劫多见。四柱皆不可见官杀，见之则不可入从强、从旺格。**日主极强旺时，应先考虑专旺格条件，若不合专旺格条件时，再考虑从旺格。**[总诀 变格(二)6]

| | 从强格 | 从旺格 |
|---|---|---|
| 日主 | **当令** | 当令或**不当令** |
| 局中 | 印星**多于**比劫，"强之极" | 满盘印星比劫重重，"旺之极" |
| 所从 | 从**印星**之强势 | 从**印比**之旺势 |
| 官杀 | 不可见，见则不入 | 不可见，见则不入 |
| 喜运 | 印星、比劫 | 印星、比劫 |
| 忌运 | 食伤、官杀 | 食伤、财、官杀 |
| 关键差异 | **喜食伤** | **不喜食伤** |

**R11-2**　专旺喜食伤流通，从强、从旺不喜食伤——**此为两格差异之处**，也是判别二类格的试金石：一格见食伤则贵，一格见食伤则破。[总诀 变格(二)6]

> **实务提示**：验格次序固定为 ①专旺五格 → ②从强 → ③从旺 → ④退回八格。前一步不合才走下一步，不可跳步。

### 3.4　从格

#### 3.4.1　总则

> 当八字日主五行极衰弱，失时弱势无根无可依存时，必须弃命以从。即四柱中克泄日主之官杀、食伤、财星三者五行，**有一行或两行最强旺数量最多**，日主顺从该五行之旺势，叫弃命从弱，取之成格，称之为"从格"。[总诀 变格(三)]

| 项 | 内容 |
|---|---|
| 成格前提 | 日主失令、极弱、**无根**、无可依存 |
| 所从对象 | 官杀、食伤、财星三者中**最强旺、数量最多**的一行或两行 |
| 三分类 | **真从**（出身富贵）／**假从**（出身较差）／**不从**（以正格论） |
| 用神 | 所从之神即用神 |
| 忌运 | 印星、比劫来生扶帮身 → 反主灾疾 |
| 忌冲 | 月支逢岁运冲 → 凶变灾厄；原局月支逢他支冲 → 平生多波折、困厄、贫乏 |

#### 3.4.2　从格四格

| 格 | 成立条件（任一组合） | 破格条件 | 富贵条件 |
|---|---|---|---|
| **从财格** | ①日主失令极弱无根 + 干支多财且旺、财透干、支财多<br>②月支为财 + 月支与旁支三会／三合成财局 + 财透干<br>③月支为财 + 支财≥2 + 见食伤生财 + 财透干 | 一见**比劫克财**；或**印星旺而逆损** | **须见官杀**才可论贵；不见官杀 → 只富而不贵，或富多贵少 |

### 3.5　化气格

#### 3.5.1　总则

> 化气格简称为"化格"。化气格共分五格：化木格、化火格、化土格、化金格、化水格。[总诀 变格(四)]

| # | 条件 | 结论 |
|---|---|---|
| 1 | **必须日干与月干或时干相合** | 方可论合化 |
| 2 | 日干与**年干**相合 | 为**争合，其情不专** → 不论合化 |
| 3 | 化神**得月令**（与月支同五行） | 方可论化，主贵显 |
| 4 | 化神成而**不得月令** | 虽可成格，**亦难贵显** |
| 5 | 化神不旺，或局中见**克化神**者 | **不论化格**；惟克化神之字被局中他字克合 → 论**假化**，须待运助方能成真、发达成就 |
| 6 | 日主须**无强根** | 方可论化；若强根与化神同五行，反使化神更旺 → **仍可入化格** |
| 7 | 化神及生化神之用神 | **均须透干**，方为真；否则化亦不真 |
| 8 | 化神须**纯粹专一** | 方为贵；杂乱则所化不真，不能贵 |

> 《滴天髓》云：「化得真者，只论化，化神还有几般化，假化之人也多贵，孤儿异姓能出类。」[总诀 变格(四)]

**运忌两条**：
- 行运**运干来克日干**，或**与日干五合** → 皆凶运，主灾厄、官司、破财、受伤。
- 「**化神一字还原**」：化神五合中任何一字被克皆凶，主破败、损财、官讼、灾祸、血光刑伤。**尤其最怕命、运、岁合会成克破化格之五行**，该运岁必凶。[总诀 变格(四)]

> **读法**：五格的"生月"都是「三合局 + 长生」的组合（木：亥卯未 + 寅；火：寅午戌 + 巳；金：巳酉丑 + 申；水：申子辰 + 亥；土：四季）。化神得月令只是最低门槛，还得"化神透干、纯粹、不逢克"，四关齐过才算真化。

### 3.6　半壁格（两神成象格／双清格）

> 八字中两种五行分别各占**二干二支**，两者力量相当，此格可分为"**两行相生**"及"**两行相克**"两种情形，为最清纯（原作"最清存"）之命。为相生或相克，两者力量应平均，不可偏重或偏轻。[总诀 变格(五)]

| 项 | 内容 |
|---|---|
| 成立 | 两行各占二干二支，力量平均，不偏重偏轻 |
| 分型 | ①两行**相生** ②两行**相克** |
| 取用总则 | 以局中**二物**为喜用神 |
| 日较强 | 取**另一行**为用神 |
| 日较弱 | 取**与日主相同之五行**为用神 |
| 取用精神 | 「亦求其中和平妥（原作"中和平很"）为取用之法」 |
| 组合形态 | ①两柱干支皆相同，两行各占二干二支<br>②四柱干支不同，但两行同样各占二干二支 |

**R11-5**　半壁格的取用不看官杀财印，只看"二物之势孰强孰弱"：日主偏强则扶另一行，日主偏弱则扶日主同行。这与八格取用（官杀优先）是两套逻辑，不可混用。[总诀 变格(五)]

## §4　杂格二十种

### 4.1　总说与用格纪律

> 古书记载之杂格名目相当繁多，现代命学者，有认为合理，或认为不合理者，莫衷一是，因此大半不取杂格论。或略而不谈。但是**根据经验，有些杂格在论命印证时，也能准确推断。尤其在用正格及变格论命，无法找出满意答案时，往往在杂格中，可找到满意答案**。习命理者，不应闲杂格麻烦，而弃之不用。[总诀 杂格]

**三条纪律**：

1. **最后才用。** 原文定了次序：正格 → 变格 → 都不满意 → 杂格。反过来先套杂格，是"以格套命"。
2. **成立条件极窄。** 多数杂格要求「无官杀」「只宜一位」「要有一字合住」「添实则凶」——破一处即不入格，不能"大致像"就算。
3. **13–18 六格原文只给名目，不给喜忌。** 原文一律写"其喜忌依命局结构而论吉凶"，这是原文的克制。**不可替它补断语。**

### 4.2　逐格

#### 4.2.1　井栏叉格

- **主日**：庚申、庚子、庚辰（原作"乙庚申"，"乙"疑为"以"）
- **条件**：地支三合成水局（申子辰），天干透三庚，「乃为全逢润下」
- **取贵之理**：庚以丁为官，以申子辰水局冲寅午戌火局，庚日得官为贵
- **喜忌**：喜水、木、金；忌火、土
- **定性**：原文自判「此格实为**金水伤官之变格**」

> 诗曰：「庚日全逢申子辰，井栏叉出世超群，丙丁寅午全无露，定是清朝富贵人。」
> 《喜忌篇》云：「庚日全逢润下，忌丙丁巳午之方，时遇子申，其福减半。」[总诀 杂格1]

#### 4.2.2　壬骑龙背格

- **主日**：壬辰日
- **机理**：用支辰暗冲戌中丁、戊；**辰多主贵**（冲起有力），**寅多主富**（合住财官）
- **喜**：行身旺、食伤运
- **忌**：南方财官（火土）之地；官星来破格

> 「壬骑龙背贵非常，大忌官星来破格，灾刑须见寿元伤。四柱辰多官爵显，寅多却作富家翁。」
> 《喜忌篇》：「阳水叠逢辰位，是壬骑龙背之乡（原作"辈子乡"）。」
> 《独步》：「壬骑龙背，寅多则富，辰多则荣。」[总诀 杂格2]

- **变通**：壬寅日而柱中多辰，亦入此格。

#### 4.2.3　六阴朝阳格

- **条件**：六辛日逢**戊子时**
- **破格**：局中见火星（官杀）
- **用量**：柱中**只宜子字一位**，多则不中——「若多一子福还悭」
- **宜**：身旺为佳
- **主**：多名胜于财，主贵
- **真正合此格者**：辛丑、辛酉、辛亥 三日
- **有破者**：辛巳（巳中丙火破格）、辛未（未中丁火破格）、辛卯（卯刑时支子）
- **运**：喜金木，忌火水

[总诀 杂格3]

#### 4.2.4　六乙鼠贵格

- **条件**：六乙日遇子时；**专取丙子时**，名「鼠贵幽元」，「无冲无破福周全」，更为贵
- **辅助**：要月通木局，日支亦为木旺之地，或水（印星）亦可
- **忌**：午来冲子、丑来绊子、卯来刑子
- **宜**：局中多见子字尤佳，为「聚贵」
- **入格前提**：四柱须**无官杀**
- **运**：岁运庚辛申酉凶悔；东方渐退；**午运大凶**（午冲子）
- **加贵**：「鼠贵带食，早为藩省薇垣之相」
- **真正合此格者**：乙未、乙亥 二日
- **有破者**：乙巳、乙酉、乙丑（坐下藏干为官杀）、乙卯（卯刑时支子）

> 为何用子（鼠）不用申（猴）？「因申中之庚金为六乙之杀，乙日用申时为官星显灵，故不取申也。」[总诀 杂格4]

#### 4.2.5　六甲趋乾格

- **条件**：六甲日见**亥时**，局中多亥字
- **忌**：行冲；见寅、巳、财星
- **主**：仁慈刚介心平
- **喜**：透印绶
- **机理**：亥为天门之位，在乾卦位内，故曰「趋乾」；甲之长生为亥，甲之禄为寅，**亥能暗合寅**，为暗合寅禄，可求富贵

> 《千里马》：「壬趋艮，甲趋乾，清朝吉士。」[总诀 杂格5]

#### 4.2.6　六壬趋艮格

- **条件**：六壬日见**寅时**，局中多寅字
- **忌**：刑冲克破、官杀来侵、**亥字添实**
- **主**：富；「六壬趋艮，智足多仁」
- **破**：逢亥月必贫
- **机理**：寅在艮卦位内，故曰「趋艮」；壬禄为亥，**寅与亥暗合**，故名「暗禄」「合禄」

[总诀 杂格6]

#### 4.2.7　飞天禄马格

- **四日**：庚子、壬子、辛亥、癸亥
- **生月**：十月（亥）、十一月（子），冬水纯阴
- **入格前提**：柱中**忌见官杀**；忌官星显露（禄难飞动）、合神羁绊（不能飞动）；**要柱中有一字合住，方不走了贵气**
- **喜**：伤官、食神，及干支本运
- **名义**：禄为官，马为财；局中财官被冲起，故曰飞天禄马

> 诗云：「禄马飞天识者稀，庚壬重子贵非疑，柱无羁绊官星现，平步青云到凤池。」
> 又云：「飞天禄马少人知，辛癸亥多最为宜，不见辟煞并惹绊，少年富贵拜丹墀。」
> 《喜忌篇》：「若逢伤官月建，如凶处未必为凶，内有倒禄飞冲，忌官星亦嫌羁绊。」[总诀 杂格7]

| 日 | 用量 | 冲起何物 | 喜（合一字） | 忌 |
|---|---|---|---|---|
| 庚子 | 多见子字 | 午中丁火（官）、己土（印） | 寅、戌、未，一字合午为妙，多则不宜 | 丑来绊子；官星 |
| 壬子 | 多见子字 | 午中己土（官）、丁火（财） | 同庚子 | 同庚子 |
| 辛亥 | 多见亥、子 | 巳中丙火（官）、戊土（印） | 申、酉、丑，一字合巳为妙，多则不宜 | 寅来绊亥；官星 |
| 癸亥 | 多亥字 | 巳中戊土（官）、丙火（财） | 同辛亥 | 同辛亥 |

#### 4.2.8　倒冲禄格（原作"倒动禄格"）

- **二日**：丙午、丁巳
- **喜忌**：**与飞天禄马同法**
- **入格前提**：局中**无官杀**
- **机理**：丙午日，午冲起子中癸水官星；丁巳日，巳冲起亥中壬水官星，故曰「倒冲禄」

| 日 | 用量 | 喜（合一字） | 忌 |
|---|---|---|---|
| 丙午 | 多见午字，无官杀 | 丑、申、辰，一字合子为妙，多则不宜 | 未来绊午；官杀（壬癸亥子）显露 |
| 丁巳 | 多见巳字，无官杀 | 寅、卯、未，一字合亥为妙，多则不宜 | 申来绊巳；官杀显露 |

[总诀 杂格8]

#### 4.2.9　财官双美格

- **专指**：壬午、癸巳 两日
- **机理**：午中丁、己为壬日之财，而午又为丁己之禄；巳中丙、戊为癸日之财官，而巳为丙戊之禄。财为马，官为禄，坐支兼得禄马财官双全 → 财官双美
- **限度**：原文自注「**但仍以全局生克制化喜忌为审度，是否富贵才最正确**」

- **附列**：日干坐支藏财官者另有 甲戌、乙丑、乙巳、丙申、丁丑、戊辰、己亥、庚寅、辛未、壬戌、癸未 等日（可作参考，非即入此格）[总诀 杂格9]

- **喜**：身旺、坐旺地、行旺运；喜食伤、财星

#### 4.2.12　专财格

|---|---|---|---|---|

| ② | 透二三干如何取 | 「斟酌其一，**以有力而无克合者为上**」——按力量与克合，不按本气排序 | 本气 → 中气 → 余气，**固定优先**（03 §2.2 第二条） | **冲突** |
| ③ | 藏干全不透 | 「轻重较量，择一有力而无克合者」——**不固定取本气** | 「藏干全不透 → 取**本气**」（03 §2.2 第三条） | **冲突** |
| ④ | 是否先论官杀 | 无此次序，直接按月支透干定名 | 「有官先论官，有杀先论杀」（03 §2.1）；八大格以杀、官居首 | **冲突（本册缺）** |
| ⑤ | 八格内容 | 正官·七杀·正财·偏财·正印·偏印·食神·伤官 | 杀·官·财·印·食·伤·**归禄**·**阳刃** | 归禄／阳刃位置互换 |
| ⑥ | 比劫取格 | 「比劫不能取格」 | 「比肩不成格」 | **一致** |
| ⑦ | 禄刃 | 归**变格**（建禄格、月刃格） | 列为第 7、8 格 | 名实之争，不影响推断 |
| ⑧ | 阴干立刃 | 「惟阴干无月刃格」 | 阳刃格亦只论阳干 | **一致** |
| ⑨ | 专旺／从／化 | 有完整成立条件与破格条款（§3.3–3.5） | 承认专旺「另成格局、不可与常格同论」，但只给一句「从格要有格才能从」（02 §6.4） | **互补：本册可补条件** |
| ⑩ | 月令会合改属性 | **无此条** | 「月令因会合改变原五行属性 → 以变化后之五行取用」（03 §2.2 第四条） | **盲派有，本册缺** |
| ⑪ | 象法／神煞 | 全无 | 盲派以象法定人事、神煞定应期（04、05 册） | **体系不同，不可互参** |
| ⑫ | 拱禄拱贵 | 「月令无神用此奇」——补救格 | 「提纲有用提纲重」——同一立场 | **互证** |

### 5.2　三处硬冲突的处置

**冲突一：透干定名 vs 节气司令。**
本册说"辰月透戊即偏财格"；盲派说"辰月生人，戊土司令才作戊论，若乙木司令则不然"。这不是谁对谁错，而是**两个层面**：
- 本册解的是**格名归属**（这个八字有几个候选格，各自的十神关系是什么）；
- 盲派解的是**当日掌权者是谁**（同一月支，初生与末生司令不同）。

**处置**：先用本册列出全部候选格 → 再用 03 §2.5 查该日司令之神 → **当候选格与司令之神一致时，格真**；不一致时按 03 §3.1 判"假格"或"破格"。**绝不可只用本册定名就下断语。**

**冲突二：透二三干，本气优先还是力量优先。**
- 本册：择「有力而无克合者」（力量优先）
- 03 册：本气 → 中气 → 余气（顺序优先）

**处置**：**两法并验**。若本气透干而无克合，两法同结论，无争。若本气透而被克合、中气透而有根，本册取中气、03 册取本气——此时以 **03 册为准**，因为盲派多一道"格之真假"判断，且其体系内"出而被冲＝破格"已有明确档位（03 §3.1）。本册的正确用法是"提示还有第二个候选"，不是"推翻本气"。

**冲突三：先论官杀，还是先看月令透干。**
本册通篇不谈官杀优先；03 册把"有官先论官、有杀先论杀"列为第一条总则，且明说"这里我们把格局和官杀分开了"[P77]。

**处置**：**以 03 册为准**。本册的 120 例是"月令能取何格"的清单，不含"官杀出格则先论官杀"这一层。凡八字天干地支见官杀，先走 03 册 §2.1 的次序，官杀不成格，再回本册查月令格。

### 5.3　合用的正确顺序（六步）

| 步 | 做什么 | 用哪册 |
|---|---|---|
| 1 | 排四柱、定月支、定日干 | 01 册 + `paipan.py` |
| 2 | 查本册 §2 对应日干那一张表 → 列出**全部候选格** | 本册 §2 |
| 3 | 查当日**司令之神**（节气深浅），与候选格比对 | 03 册 §2.5 |
| 4 | 有官杀 → 先按"有杀先论杀"过一遍，官杀不成格再回来 | 03 册 §2.1 |
| 5 | 判真／假／破／不成 四等 | 03 册 §3 |
| 6 | 见禄刃、专旺、从、化气、半壁之象 → 先用本册 §3 验变格条件；见极窄条件吻合的怪格 → 本册 §4 查杂格 | 本册 §3、§4 |
