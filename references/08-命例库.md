## 一、格局成败类

> 本类 40 例（001–040），是全书主体。核心争点：**格与局的分判**（格要出干、局要成气）、**真官假官**、**官是否傍格**、**四库取格的多变性**。凡「同时辰差一字而格局全变」的对照造，均相邻排列（005/006、046/047/048）。

### 001｜正财格劫财破局（格成而局破）
- **四柱**：甲寅 / 戊辰 / 己巳 / 乙卯（原文如此；[P28] 另有校读作「甲寅 戊辰 乙巳 己卯」，未定）
- **性别/年代**：乾造；作者明言「临时拟造，未校对真假」，无年代
- **大运/流年**：未及
- **断语**：
  - 辰月戊土司权，干透戊土 → 正财格，格神显现
  - 甲己有化木之势、乏化土之功 → 甲己不化土，故「成格不成局」
  - 年柱甲寅为劫财，「分我土地的养料」→ 劫财局
  - 结论：**财星格、劫财局，破局，且破得很厉害**
- **依据**：月令司权定格；格神须出干；甲己合化须有条件（辰中乙木余气助木、无化土之功）；劫财夺财破局 [P27–P29]
- **应期**：无
- **备注**：作者补注「多好的格局，要是没有这个寅字，岂不是格局完美、发达富贵垂手可来？」并声明此例不涉「三会木局成仁寿」之说。日柱「己巳」与文中「乙木日主」不合，属 OCR 疑误，引用时须核原书。

### 002｜逢官看印·印星无根成破局
- **四柱**：癸巳 / 辛酉 / 丙午 / 丁卯
- **性别/年代**：未标
- **大运/流年**：未及
- **断语**：
  - 八字本应「逢官看印」，可惜**印星无根、归于败地**
  - 伤官又出干破坏原局 → 非真局，是**破局**
  - 癸水自顾不暇，管不动丁火；即使岁运来助亦枉然
- **依据**：官星须印护；印无根则不能为用；伤官出干破格 [P34–P35]
- **应期**：无
- **备注**：作者喻「破局也是局，这个局字还是有的。好比抗战时期的保安队——说是保安为人民，实际是害人民的」；又喻「它原来就是个病秧子，吃一个肉包不会来精神」。

### 003｜财官印俱全而三宝无覆载
- **四柱**：辛卯 / 癸? / 甲辰 / 己?（月干、时干 OCR 缺）
- **性别/年代**：未标
- **大运/流年**：未及
- **断语**：
  - 看着「财官印」俱全，其实什么也不是
  - **三宝没有覆载，财官禄马皆背道**——背的是**月令之道**
- **依据**：格局以月令为纲；三宝（财官印）须有覆载（根气承托），否则徒具其形 [P35]
- **应期**：无
- **备注**：此例与 004 互为反照：一为「表面美、实无用」，一为「表面丑、实佳」。

### 004｜印格忌财·劫财出干反为护印
- **四柱**：乙卯 / 丙子 / 甲寅 / 己巳
- **性别/年代**：未标
- **大运/流年**：未及
- **断语**：
  - 表面看有劫财不好，不知**印星格忌财**，有劫财出干反而有利命局
  - 正印深藏不露，可以稳吃
  - 庚金七杀时上归根，官禄盈余
  - 瑕疵：此象顶多**克妻、钱财不易成聚**；然印星在月中，岂能贫困
- **依据**：印格忌财，劫财去财则护印；印在月令得气；七杀时上归根 [P35]
- **应期**：无
- **备注**：作者引申「这里说明劫走了财才好呢」——如有人舍得花钱放生，为的是护印（健康、福分、持久利益、面子、寿元、名声）。

### 005｜伤官格身旺喜财（羊刃护身）
- **四柱**：癸卯 / 戊午 / 甲午 / 丁卯
- **性别/年代**：男
- **大运/流年**：辛酉（5 岁起）……〔OCR 残缺：「5 岁 / 45 岁走癸丑」并存，与文中「21 岁甲寅」「27 岁乙卯」不合，**标 OCR 疑误，不宜引用具体干支**〕
- **断语**：
  - 27 岁戴重孝，应在秋天；不缺钱、富而有余，有工作也有生意，发土上财；一生钱财聚散无常，常为亲眷耗财，「有钱就有人要，有人还不还，去得容易来得快」
  - 四十岁前克妻再娶，先大后小；两妻两孩子，另有损伤的孩子
  - 从武武职，喜文，正县级职位；文化不少、文凭不高
  - 2009 年（己丑）有暴病，尤须防血液、心脏，发病不及防范

### 025｜墓杀格（凶神得地得用）
- **四柱**：己酉 / 戊辰 / 戊午 / 乙卯
- **性别/年代**：乾造（学员作业）
- **大运/流年**：未列
- **断语**：
  - 徒之思路：月令所藏戊比、乙杀、癸财三物皆入库；其中乙木七杀被「挖出」透时干，时支卯又为杀之禄 → 七杀格成
  - 苍正：不只七杀成格，而是**七杀归禄，霸道得很**；且此非「时上一位杀」，而是「**墓杀格**」——「一个很有前途也很危险的格局」
  - 凶神得地得用才好，此杀须化解才成材，「前途无量是它，灾祸频临也是他」
  - 用神与辅神：七杀成格即以七杀为用神；喜印、刃、禄、食神化解，首推印（「一仁可化」），次食
  - 实况：天干印食皆不现；地支日支午为印，但午与月令辰相配「土旺火休」，引归时上此印又为病 → 完全无力之印，暗示杀性无人可化、随时爆发
  - 食为金，月令土旺金相，金必有力；但天干无食，地支只有年支酉——**阳金为伤官，阴金才是食神**，故酉不能助七杀格
  - 结论：用杀喜印而印无力，喜食而食不见
- **依据**：四库藏杀透干为墓杀格；杀归禄；印化杀、食制杀；酉为伤官非食神 [P227–P229]
- **应期**：未及具体年
- **备注（四问）**：
  1. 平头煞（甲、戊、丙等）落此造是否有影响？→ 苍给五组字形分类。
  2. 月支辰为墓库需钥匙打开吗？卯辰相害能开库吗？→ 苍：「吉物专怕明藏，深而有祸；凶物最喜隐藏」；**只有冲能开库，刑害破虽能扫开墓库终无好结果**；「冲」是不经意磕撞，「刑害」是设计夺取（必犯法纪报应）。
  3. 酉合辰、卯害辰，又合又害如何用？→ 须分谁害谁，再以职司类象取：卯为太冲（御医、司太监一类）、辰为大罡（警察等执法监刑之官）、酉为从（利益财政之官）→ 联想可见「他贪财犯法进监狱」。
  4. 何字为好字、何字为坏字？→ 好字即官印禄，坏字即枭伤杀劫刃；「有分有用为宝，无用为闲，反势为灾，不可执泥一语」。

- **备注**：此例是本块唯一「口诀—规则—应期」三层齐备的完整示范，作者用它证明口诀不需旺衰。另有作者明言：「我不认可通关之说，但是五行的相顺是一个好的兆头」；「食神护官须看得力，得力则能用，不得力则助纣为虐」。

  - 年：甲寅（1974 甲寅年正月初一甲子，正月十三立春未时；小月为三、闰四、五、七、八、十一月）
  - 月：八月＝癸酉（五虎遁「甲己之年丙作首」→ 丙寅、…、癸酉）
