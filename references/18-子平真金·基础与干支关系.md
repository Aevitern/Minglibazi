- **午与未合（六亲）** → 祖辈老人有重婚；下代必出文人；合入其格→亦出经济犯罪者。摘引：「午与未合，祖辈老人有重婚，下代必出文人。合入其格，亦出经济犯罪者。」[Z024]

- **不知物性而空言玄妙** → 缘木求鱼。摘引：「不知天地万物之性，空言玄妙，岂不是缘木求鱼？」[Z024]

## §8 地支六害（《金书诀》、害破之辨、合→冲→破→害→刑→绝次第、六首详论）[Z029–Z031]

> 对应影印图 [Z029]「图.017号.地支六害图」（无可提取文字）；定义、次第论出 [Z030]，六害详论六首出 [Z031]。

- **害之定义** → 损害损伤、相互伤害；十二地支相害是「一个十五度角的关系」，十五度角是死角、代表死路一条，世间万事万物皆忌此境。摘引：「十二地支相害，是一个十五度角的关系。十五度角是个死角，代表死路一条，世间万事万物，皆忌此境。」[Z030]
- **《金书诀》** → 六害之人忌日时，老年残疾苦何依；又逢羊刃神相蚀，不中锋芒虎亦欺。结论：命犯六害大忌干支相伤，日时上最紧。摘引：「六害之人忌日时，老年残疾苦何依；又逢羊刃神相蚀，不中锋芒虎亦欺」[Z030]
- **害字最怕死绝** → 见死为害死，见绝为绝害；害人至于死绝，自己也好不了。摘引：「师傅，害字最怕死绝，见死为害死，见 绝为绝害，害人至于死绝，自己也好不了，所以害字入命最令人畏惧。」[Z030]
- **斥「六害是神煞无甚用处」** → 「真是可 笑，愚昧之极也」。摘引：「有人说六害是神煞无甚用处，真是可 笑，愚昧之极也。」[Z030]
- **破与害之辨** → 破是损人利己（可能无意间造成破坏）；害是损人不利己（有预谋向他人施加伤害，拿著炸弹去炸别人，弄不好也会炸到自己）；破伤自己是「不小心」，害伤自己是「活该」。摘引：「破是损人利己，而害是损人不利己……拿著炸弹去炸别人，弄不好也会炸到自己。」[Z030]
- **「合」之诸义** → 不单指和好，还指和睦、和台、求和、讲和、说和、媾和、合适、融合、胶合、凑合；凡隐忍、潜伏、掩盖之另一形态，到忍无可忍→产生冲、破、害、刑、绝。摘引：「合，不单指和好，有时候还指和睦、和台、求 和、讲和、说和、媾和、合适、融合、胶合、凑合……到了忍无可忍的时候，就产生了冲、破、害、刑、绝。」[Z030]
- **破之诸义与解灾用法** → 破坏、破裂、破旧、破除、破解、破釜沉舟；解灾时经常找一个「破」的日子，起到破灾作用；破遇冲则加快破裂速度。摘引：「比如在给人家解灾的时候，经常找一个「破」的日子，就起到破灾的作用。破 的方式不像冲那么激烈，当它遇到冲得时候，就等于加快了破裂的速度。」[Z030]
- **冲之定义** → 双方对立的矛盾、事情在不预知情况下发生；可用「遭遇、突发」形容；无论双方是否相识都可能发生（如陌生人撞车＝遭遇，共事者分歧＝突发）；虽情节激烈但无可记恨。摘引：「冲是双方对立的矛盾，事情在不预知的情况下发生。我们可以用「遭遇、突发」这样的词来形容它。」[Z030]
- **冲后有害** → 害是因冲突过分、又无法在冲突中找到至胜点，只好在背后搞鬼；或本两人冲突又加进一人趁机捣鬼、说坏话、煽风点火→产生暗害。摘引：「害是因为冲突的过分，又无法在冲突中找到至胜点，只好在背后搞鬼……这时产生了暗害。」[Z031]
- **害＝冲突不能一次性明了（单纯地）地解决／「合」本是一个大祸根** → 先有合而后又冲、破、害、刑、绝。摘引：「「合」本是一个大祸根，从而可知，先有合而后又冲、破、害、刑、绝。」[Z031]
- **刑之定位** → 在冲的基础上出现第三者，事情摆到明面上，第三者处于调解角度；害不能解决的问题都交给刑；刑代表法律、规矩、规则、规定，本具调解义，调解不好才真正称为刑、变作惩罚。摘引：「刑代表法律、规矩、规则、规定，它本来具有调解的意思。正是因为调解不好最后才真正的称为刑，刑变作惩罚。」[Z031]
- **合／冲／破／害／刑／绝之经营比喻** → 共同开拓事业＝合；利益分配不均争执＝冲；一人懒于经营或想退股＝破；一方做假账、一方进假货＝害；严重分歧须第三者调解（诉诸法律）＝刑；惩罚不能解决、山穷水尽生死决绝＝绝。摘引：「比如两个人合作经营，共同开拓事业称作合。因为利益分配不均，发生争执称作冲。」[Z031]
- **「绝」之取象** → 官司打到一定程度，法律裁决仍不能泄（都肥了第三者／官家）→第三者把事做绝、两人把路走绝，统称作绝。摘引：「有时候官司打到一定的程度，法律裁决仍不能泄 都肥了第三者（官家），可以看出第三者把事做绝了，两个人把路走绝了，统称作绝。」[Z031]

### 8.1 《金书诀》与【六害详论】六首 [Z030–Z031]

> 《金书诀》云：「六害之人忌日时，老年残疾苦何依；又逢羊刃神相蚀，不中锋芒虎亦欺」。[Z030]

> 【六害详论】[Z031]
> 子未害：子未相穿骨肉疏，老来何依受孤独；亲子不能合父母，夫妻难得路共途。

## §9 地支三刑（成立条件、应灾关键、刑随旺衰、取象、四组诗）[Z032–Z034]

> 对应影印图 [Z032]「图.018号.地支三刑图」（无可提取文字）；详论出 [Z033]，四组诗出 [Z034]。

- **子卯酉（卯子午）三刑** → 只说子卯相刑是不对的；子刑卯、卯刑酉、酉又自刑，卯刑子、子刑午、午又自刑；因卯酉、子午相冲解去后边之刑，故剩下子卯、卯子对刑。摘引：「其实只说子卯相刑是不对的，子刑卯卯刑酉，酉又自刑：卯刑子子刑午午又自刑」[Z033]
- **三刑＝三个「太极点」之间的矛盾** → 去掉午酉就不能形成三刑；「子刑卯无午不刑，卯刑子无酉不刑」。摘引：「其实三刑指的就是三个「太极点」之间的矛盾，若是去掉午酉，就不能形成三刑，这里需要说明的就是，子刑卯无午不刑，卯刑子无酉不刑。」[Z033]
- **丑未戌之刑** → 同为三个地支，但丑未戌都是杂气，表面三个小太极点、实际关系复杂，隐藏问题太多难以一时解决；一旦引发就不好停止，流年已过刑灾还在。摘引：「丑未戌都是杂气，它们之间表面是三个小太极点，实际关系非常复杂……很多人流年已过，刑灾还在。」[Z033]
- **丑未戌之刑关键在丑** → 命有戌未，流年逢丑→应灾尤重（须命柱上原有灾象）；若刑得禄马→福禄连绵，又不相同。摘引：「此刑的关键在于丑，如果命有戌未，流年逢丑，应灾尤重，当然必须是命柱上原有灾象，若是刑得禄马，则福禄连绵，又不相同。」[Z033]
- **三刑土煞不入东南／辰不参与** → 东南方是水的归宿，再多的土到那里也是石沉大海；故四土之中辰没有参与这种象。摘引：「三刑土煞，不入东南，因为东南方是水的归宿……所以四土之中，辰没有参与这种象。」[Z033]
- **寅亥丑以及辰午酉亥自刑** → 不是说见寅亥见亥见丑午酉见酉等等；应该说，辰亥见午或酉都能形成三刑。摘引：「应该说，辰亥见午或酉都能形成三刑。」[Z033]
- **辰午酉亥这组三刑** → 辰和亥二者不能缺一；午和酉都是五行正气，其中有一个就能引发相刑；辰和亥缺少一个→刑不能完全成立；命中逢此→虽犯刑而不能刺配。摘引：「所以辰午酉亥这组三刑之中，辰和亥二者不能缺一，而午和酉都是五行正气，其中有一个就能引发相刑」[Z033]
- **自刑** → 多主自误、自责、自怨、自弃、自残、自杀、自己放枪打自己等，包括自杀、自灭的迹象。摘引：「自刑，多主自误、自责、自怨、自弃、自残、自杀、自己放枪打自己等，包括自杀、自灭的迹象。」[Z033]
- **三刑本于天体运行** → 古人研究三刑是根据天体运行的轨道观察出来的，「这绝对不是迷信」；斥「刑之意无所取者」及把三刑取象和干支生克搞到一起（如戊中辛金刑去未中乙木）为「滑天下之大稽」。摘引：「古人研究三刑，是根据天体运行的轨道观察出来的，这绝对不是迷信。」[Z033]
- **刑之取象（活学活用）** → 刑罚、囚禁；说树木代表砍伐；测失物遇生旺→牛马已被人家圈起来（代表关押），死绝→被人家给杀了；用于人＝违法犯法迹象，用于动植物依类相取，绝不可执泥。摘引：「测失物，遇生旺直接推断牛马已经被人家给圈起来了（这里代表关押）；死绝则可以 说被人家给杀了。」[Z033]
- **刑随旺衰断** → 刑到死绝之地→主死刑；刑到胎养休囚之地→主关押；刑到生旺之地→亦主升官发财，不要千篇一律。摘引：「刑到死绝之地主死刑，刑到胎养休囚之地主关押，刑到生旺之地亦主升官发财，不要千篇一律。」[Z033–Z034]
- **八字有刑** → 吉则掌刑，凶则受刑；亦可理解为肌肤损坏、肢体伤残，或躺在担架上被人家抬著、倒在推车上被人家推著。摘引：「八字有刑，吉则掌刑，凶则受刑；刑亦可理解为肌肤损坏，肢体伤残」[Z034]

## §12 本册独特说法（单列）

> 以下五条为本页段自成一系、与通行子平及旧包旧册相左或独有的说法，单列以便检索与口径声明。

1. **害为「十五度角死角」** — 「十二地支相害，是一个十五度角的关系。十五度角是个死角，代表死路一条，世间万事万物，皆忌此境。」[Z030] 以几何角度重新定义六害，并斥「六害是神煞无甚用处」之说「真是可 笑，愚昧之极也」[Z030]。
2. **三刑须三个太极点，且「辰不参与」** — 「其实三刑指的就是三个「太极点」之间的矛盾，若是去掉午酉，就不能形成三刑……子刑卯无午不刑，卯刑子无酉不刑」[Z033]；又「三刑土煞，不入东南……所以四土之中，辰没有参与这种象」[Z033]。按：此「辰不参与」就四土（辰戌丑未）之土煞刑而言，与 [Z034] 四组诗中「【辰亥酉为自刑之刑】」并存，本册内部即有张力，详见 §14。
3. **「硬说合化要提纲」（直斥以月令定合化）** — 「俗人不知三合故，硬说合化要提纲！」[Z022] 以「俗人」「硬说」直斥以月令（提纲）定合化之说。此语出【合会诗曰】，就**地支三合局**立论，与 14 册 §1 天干五合六化表、10 册 §9.3／§9.4「令星查判」之关系见 §14。
4. **「先合后冲破害刑绝」的关系次第／「合」本是一个大祸根** — 「「合」本是一个大祸根，从而可知，先有合而后又冲、破、害、刑、绝。」[Z031] 并以合／冲／破／害／刑／绝配「两人合作经营」全过程（共同开拓＝合、利益争执＝冲、退股＝破、做假账＝害、诉诸法律＝刑、山穷水尽＝绝）[Z031]，自成一整套关系发生论。
5. **德可解绝** — 「凡命有德，遇绝无妨，若无德字，见绝有伤」[Z036]，所立之德为天德、月德、岁德、日德、阴德五目，其中「阴德＝食神换禄」「命带阴德主人三世有德，乃大贵人之命」[Z037] 为本门自造取法。

### 14.1 三刑「是否又是一套」的结论（必答）

旧包三套为：① 10 册 §2.7 图卡四组（寅巳申／子卯午／丑未戌／辰酉亥）；② 06 册 §3.5 文字本（寅巳申、丑未戌；子卯单刑；辰午酉亥自刑）；③ 14 册 §10 推导式（寅巳申、丑戌未由火金两方推导；子卯另立；午酉自刑）。14 册 §10.3 已定「三套并存，断前声明」。

**本册 [Z034] 四组诗名录与口径①完全相同，不是第五套名录**；但 [Z033] 释文以「三个太极点」「辰不参与土煞」「辰亥不能缺一」「本于天体运行」另立成立机理，既不采口径②的子卯单刑、辰午酉亥自刑，也不全同口径③的火金两方推导与午酉自刑，构成**「同名录、异机理」的第四种表述**。故须与旧包三套**并列登记为四套**，断刑前务必声明所用口径，**并列存疑，不得混用**，不得以本册「辰不参与」去改 10 册图卡的「辰酉亥」，亦不得以 14 册推导式去消解本册「三个太极点」。
