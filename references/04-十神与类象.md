## 一、总则：十神不许孤立看

### 1.1 十神从哪里来

十神不是十个标签，是五组生克关系的十个面：

| 组 | 十神 | 与日主关系 | 书中一句话定义 |
|---|---|---|---|
| 官杀 | 正官 | 异性克我 | 「官者，管也」，一切管束我的事物 [P139] |
| | 七杀 | 同性克我 | 克力重，「古人视七杀如猛虎」 [P140] |
| 财 | 正财 | 我克异性 | 一切供我使用和支配的事物 [P141] |
| | 偏财 | 我克同性 | 额外的、附加的、意外的那一些 [P141] |
| 印 | 正印 | 异性生我 | 既能抚养我，又能文饰我 [P141] |
| | 偏印（枭） | 同性生我 | 不情愿付出其生力之象 [P142] |
| 食伤 | 食神 | 我生同性 | 耗我精力，吐我精华，故又叫秀神 [P143] |
| | 伤官 | 我生异性 | 比食神「来得更猛烈些」 [P143] |
| 比劫 | 比肩 | 同我同性 | 助我之力，也分夺我财物 [P144] |
| | 劫财 | 同我异性 | 助力小些，破坏力大些 [P145] |

### 1.2 四吉四凶

> 十神之中，以财、官、印、食为四吉神，以杀、伤、枭、刃为四凶神。四吉神显示温和、文静之气，如盛世良臣，以文教德化来治国；四凶神显示刚暴、忤逆之气，如乱世枭雄，以长枪大戟来戡乱。食神温和，正官顺从，正印安定，命局多者则为人谦和；劫财强悍，七杀暴烈，伤官忤逆，命局多者则为人乖戾。[P146]

> 一般凡命局财多则愚，官多则贱，印多则孤，伤多则害，刃多则残，禄多则贫，马多则奔波，冲多则不宁，合多则热情，阳多则坦荡，阴多则深沉，库多则损六亲；无财不实在，无官少压力，无印乏福泽，无伤不新奇，无杀不威风，无根难自立。[P146]

**R1** 财多 → 愚；官多 → 贱；印多 → 孤；伤多 → 害；刃多 → 残；禄多 → 贫；库多 → 损六亲。[P146]

**R2** 命局缺某一神，即缺该神所主之气质：无财不实在、无官少压力、无印乏福泽、无伤不新奇、无杀不威风、无根难自立。[P146]

**R3** 财官＝名利（众人所求）；印食＝学问技艺（博取名利之工具）；比劫＝身体与同仁（资本与人气）。→ 三者齐备方成完整结构。[P146]

### 1.3 十神三态：义象、六亲、心性

书中每一神都按四层写：**物象（本义）→ 六亲 → 心性（喜／忌两态）→ 行为**。类象取用即在四层之间来回换算，不可只取一层。

**R4** 十神为喜而不受损 → 显良性一面；为忌而无制 → 显恶性一面；**受制约过头 → 显现相反的一面**（如枭印制伤官过头，则不见伤官之性，只见枭印之性）。其它十神皆同。[P144]

**R5** 十神不能孤立取象：

> 八字上的十神都不是孤立存在的，每一神都与其它某神有着这样或那样的关系，若是将它们拆开来说义象，所得到的义象难免就会是不完整的或是被扭曲的。[P140]

（作者此语针对「八字没有官星就不会当官、女命不会有丈夫」一类单神论断，并举「食神有气胜财官」「财旺自能生官」为反证。）[P140]

### 1.4 好字与坏字（盲派术语）

**R6** 好字＝官、印、禄；坏字＝枭、伤、杀、劫。→ 「有分有用为宝，无用为闲，反势为灾，不可执泥一语。」[P229]

**R7** 吉物宜藏，凶物宜露：「八字中吉物专怕明藏，深而有祸；凶物最喜隐藏，关则……」（原文后半 **[P228 不可读]**）。→ 吉神藏深反主祸，凶神藏而制之反可用。[P228]

## 三、十神分述

### 3.1 正官：管束之神

> 正官为克我之物，官者，管也。表示一切管束我的事物，如父亲、上司、老板、头领、官吏、政府、政策、法律、法规、纪律、制度、公约、命令、责任、教养、任务、负担、压力、禁忌、主控力量、管理能力、主管部门、监管部门、仲裁部门等等，均由正官来表示。[P139]

**R8** 正官与七杀之别在阴阳：正官异性相克，克力稍轻，「具有约身引善的作用」（如父母管教子女、教师约束学生）；七杀同性相克，克力很重，「如暴对待百姓，敌军对待俘虏，动辄有杀身之祸」。[P140]

**R9** 官杀之两面：好的一面是有名誉地位（乌纱帽、勋章、奖状），能约束人使人上进；坏的一面是「一生都被名誉的缰绳牵着鼻子走」，制度使人机械、命令使人蠢笨，「官杀成了项上的枷锁，成了头上的紧箍咒，成了脚下的铁锁链」。[P140]

**R10** 官星不能单看有无：「没有官星就不会当官、女命不会有丈夫」是孤立看十神之误——命书另有「食神有气胜财官」「财旺自能生官」。反过来，有官星也未必能当官，走财运时倾家荡产、妻离子散者亦有之。[P140]

**R11**（作者主张）官者，八字之天然用神、先天用神。「你用也得用，不用也得用；一旦坚决不用的，就会出现大的祸害了。」[P223-224]

**R12** 官星须看「载」与「覆」：官星无根、不得覆载、无旺气 → 假官，可称「败格之官／败局之官／无用之官」→ 命有贵气之象而实不能用。[P244]

**R13** 月令为官星出干得用：若是「长生官」→ 逐步提拔；若是「帝旺官」→ 一时兴旺；再引归时上，得地则久，失地则终败。[P240]

### 3.2 七杀：攻身之神

**R14** 七杀有制 → 衣禄丰；若干上透食神、支带合 → 儿孙满眼受褒封。[P150]

**R15** 身弱杀无制 → 多生灾祸；再行官杀强地 → 带疾遭刑、丧身。[P151]

**R16** 制伏太过 → 贫儒；岁运走财旺地使杀「苏醒」→ 反发威得名。[P151]

**R17** 杀重制轻 → 时岁有颠覆之危；杀轻制重 → 虽学无成、为人到底遭屯（仕途困顿）。[P146]

**R18** 食伤恰好制住七杀（杀略偏旺亦可）→ 出人头地、做一番事业。[P146]

**R19** 伤官与七杀并见 → 本为「命中嫌」；能制伏调和则化权；日弱又无制 → 「兢兢如抱虎而眠」。[P151]

**R20** 偏官怕冲多；身强制伏 → 贵在中和；身弱虎强 → 祸患。[P151]

**R21** 身强杀浅 → 官非不宁；杀重身轻 → 终身有损。[P149]

**R22** 七杀有制化权＋身旺＋印助 → 武职功名、威镇边疆；杀刃双显 → 位至王侯。[P150]

**R23** 月令杀星旺强 → 多「上顶下端」（上克兄姐、下克弟妹），并祸及好友；女命杀多 → 婚姻多次。（原文此段后半 **[P149 部分不可读]**）[P149]

### 3.3 财星：养命亦害命

**R24** 财旺生官 → 因斯取贵；「衣紫腰金，财辅官旺」。反过来说，官星无财相辅叫**孤官无辅**，做官不大、做不久。[P147]

**R25** 财生七杀而身衰 → 或贫或夭；财逢杀党 → 夭折童年。[P147]

**R26** 日主太弱，或财多生杀 → 破祖、劳碌之命。[P147]

**R27** 财多身弱 → 富屋贫人、惹灾；行比肩（身旺）运 → 富贵荣华次第来。[P153]

**R28** 财神透干而身旺 → 尚可；逢比劫同值 → 一生名利被分张。故「财神忌透只宜藏」。[P152]

**R29** 财格岁运逢阳刃 → 克妻（「房中妻哭两三场」），甚则孤寡。[P152]

**R30** 财多无根 → 全凭时柱印星助身；逢印生 → 兴家；印被破 → 一场空。[P152]

**R31** 偏财最忌比肩同位；身强财旺 → 福；带官杀 → 更妙；若带正官而劫星透露 → 福难成，再行劫运 → 祸百端。[P153]

**R32** 财有而不长久、虽发而不能聚 → 「财源不足，财命不厚」（如癸在申月死地又自坐败地即是）。[P238]

### 3.4 印星：大靠山与大包袱

**R33** 印格喜官星，运入官乡 → 福禄清；行死绝运 → 身不利；再行财运 → 百无成。[P154]

**R38** 印多 → 老而无后；伤枭两备 → 子懦妻愚；枭食并见 → 寒必彻骨；日坐枭或枭重 → 因食而疾。[P148]

### 3.5 食神：福神、寿星、愁神

作者为食神单列一节（P171–174），是本册十神中唯一享此待遇者，故须分「成格之食神」与「过多之食神」两种读法。

**R40** 食神多了（**不含成格、不含专旺成气**）→ 「愁神」：女命嫁夫暗伤身；克父母（奶水供给者多故易为养子）；精神外泄易成「疯」；艺术家之象。[P171-174]

> 食神多了是愁神，女子嫁夫暗伤身；不是花街寻败柳，就是酒巷乱真魂；[P171]

> 苍注：食神本是一朵花，人家富贵顶数它，财官印〔食〕不妨害，为人厚重叫人夸！[P171]

> 男命食神多又重，克得椿萱命无根；过房抱养尚可免，不出祖宅做疯人。[P174]

**R41** 食神过多不直接克官，而是「左右正官意志」→ 把丈夫慢慢变成无奈的废物；伤官则言语尖刻、当场伤人。二者伤官之方式不同。[P172]

**R42** 食神之良性：能生财星、制鬼星、合官印；男子得之多意外之福、中介取无意之财；「既然鬼邪不侵，寿元必保，所以活得时间会很长」。缺点是好坏不分、被人陷害也看不出来。[P172]

**R43** 食神制杀 → 吉非常；财旺 → 妻荣、子更强。[P153]

**R44** 食神逢禄（天厨）→ 富；若逢冲克空亡、官杀混杂 → 福减；死绝运临印地 → 反为寿星。[P153]

**R45** 食神不喜逢印绶；见财官 → 福更隆；逢枭遇劫 → 总成空。[P153]

**R46** 食神居先、杀居后 → 平生衣禄最厚；杀近食神（杀先食后）→ 有殃、终日奔走。[P153]

**R47** 食神有气胜财官，前提是食神本身强旺得本气；若被反伤夺食 → 辛苦祸千般。[P153]

> 食神无损寿绵长，遮母（疑为「枭母」）逢之不可当；若无偏财来救护，命如秋草带冬霜。[P153]

### 3.7 比肩：禄元

**R65** 比肩在地支称禄元，「有爵禄、俸禄、利禄等义象」。命局无官星时，通常拿它当官星看。[P144]

> 日干坐禄，杖地造屋；日禄归时没官星，号曰青云得路；正官得禄，有夫必贵；偏财得禄，生父必显；比肩得禄，兄弟名高；食神得禄，有子必荣。[P144]

**R68** 建禄（禄居月支）→ 男命不居家、白手成家；月禄无伤 → 家有兄长可承业。[P181]

**R69** 劫财之破坏力大于比肩，性刚强急躁，「故劫财称为阳刃，意思就是像把刀」。通常与七杀、伤官同等看待，尤其是**克父、克妻、克财、惹祸伤身**的重要信息标志。[P145]

**R71** 凡月令建禄 → 难招祖业、平生见财不聚，却病少寿长；再行比劫运 → 克妻、妨父、损子，或官非破财。[P148]

**R75** 阳刃重逢又逢合 → 心性气高强；刑冲太重 → 多凶危；有制 → 方保吉昌。[P154]

**R76** 刃逢七杀而运行官乡 → 贵异常（破害刑冲反为吉地）；忌合财旺之运 → 防灾致身殃。[P154]

**R77** 比肩阳刃格，须见官星与杀乡；原命无官杀制，再行比劫运 → 祸难当。[P154]

**R78** 日干旺甚无依倚 → 喜岁运行财地；原命有财见财则发，原命无财见财 → 寿夭。[P154]

## 四、取象五法（本册核心）

作者自述取象之法共五：「变通、深刻、正确、机巧、果断」，全部以同一造示范——**庚戌　乙酉　丁未　丙午**（乾造）[P241-242]。五法不是五个层次，而是五道工序：先换视角，再往深推，再校准确，再找巧门，最后敢下断。

### 4.1 第一法：变通

> 第一：干支的取象在于变通，就是把十神之间可以反复互换交叉来看，以我看彼，以彼看我。[P241]

**R80** 同一地支在不同十神视角下身份不同：此造丁以酉为**偏财**、乙以酉为**偏官**、庚以酉为**阳刃**。→ 庚金有阳刃，即等于丁火有阳刃。[P241]

**R81** 一神之凶即诸神之凶：丁火命虽自身无刃，亦「早晚会发生阳刃导致的血光类的事情」，只是**发生在谁身上**另论。[P241]

**R82** 变通之后须再定「落在谁头上」：酉能冲卯破子 → 可能涉及乙之偏印，也能涉及癸之偏官。[P241]

**R83** 六亲转位亦用变通：甲以丁为伤，丁以戊为伤，戊以辛为伤；层层递推，可把「命主之灾」转换为「某六亲之灾」（详见 5.3）。[P236]

### 4.2 第二法：深刻

> 第二：干支的取象在于深刻。[P241]

**R84** 命主出生未离乡 → 可直接断其家西北方有军营、庙宇、砖场、轧钢厂、铁匠铺、石灰窑、刑场、电视台网络转播塔之一类（庚酉金气之象）。「没有理由的说出来，可能就会很准」，具体是哪一种须更深一层分类。[P241]

**R85** 未为花园、为园丁 → 凡与学习、读书有关的地点，一律往西南方安排（幼儿园南方或东北，大学西南）。[P241]

**R86** 深刻不等于乱猜：作者自述每断必暗加一至数柱六壬，「八字即死六壬，六壬乃活八字也」——八字是死的，时空是活的，取象须临时取，不可执八字为宗。[P233]

### 4.3 第三法：正确

> 第三：干支的取象在于正确。[P241]

**R87** 神煞一律以「下方」（流年太岁）查，不以年干、日干查。[P241]

**R88** 癸巳年为此造断两贵人：一在正东、属兔、水命、方脸双眼皮；一在东南、属蛇、水命、双眼皮、略平凹脸型。[P241-242]

### 4.4 第四法：机巧

> 第四：干支的取象在于机巧。[P242]

**R89** 戊子运、己卯流年、30岁 → 卯冲酉（财）；卯为偏印；庚见卯为胎 → 「妻子临胎地」→ 断妻怀胎。[P242]

**R90** 乙克己（岁君），幸有庚合乙 → 解除乙克岁君之灾。并申明：子平所言「日克岁君」不单指日干，批命时可随时把其它天干换到日干位置上看。[P242]

**R91** 时干丙火被引动 → 通关；「被引动才能通关」，不引动则火不通关，灾祸就大。时干亦代表孩子 → 孩子是主要通关吉星 → 「喜中有忧、忧中有喜」，盲派称「一俊遮百丑」。[P242]

**R92** 月令酉亦受冲，财代表妻子 → 妻子日子不好过；月令之财为尊长 → 老人不安定。[P242]

**R93** 卯酉戌相害 → 害到母位、父腹；若妻怀孕，则年支「母亲之位」可暂让给妻子（「多了一个做母亲的人」）。[P242]

### 4.5 第五法：果断

> 第五：干支的取象在于果断。[P242]

**R94** 木无水生又受克 → 目疾（近视、色盲、雀目）。[P242]

**R95** 庚金有阳刃 → 肠胃病、痔疮、小肠疝气；「越是引动酉的时候，庚金越不好」，因支中另有戌害酉，这个害就是「时不时的捣乱」。[P242]

**R96** 乙为肝、庚为肠道 → 断病可直接落到脏腑。[P242]

**R97**（作者评语）学员断「夫有外遇」「财源不厚」诸条，作者批：「这里面的取象用法非常得利，用得如神出，就应该这样，果断，这样才能把学到深处。」[P238]

### 4.6 三条总原则

**R98** **小者数，大者象。**

> 小者数，大者象；有数理而后开花结果是为象；小者气，大者类也，有气机而后孕育胎化是为人。[P259]

→ 象在数之上，不可执数废象；数只是骨，象才是肉。[P259]

**R99** **非可以所见者知。**

> 非可以所见者知！[P259]

→ 不可只用肉眼可见的干支关系定象，须参时空、地理、气象。同一天生日，生于中原多直，生于南方水乡多敏，「此大星所射，气数不同」。[P259]

**R100** **取象须多角度**：「不能只是在一类十神中看」；同一象（如墓库）既是六亲之位，又是「夫妻合房的地方」。[P234]

**R101** 取象次序：先分男女（阴阳）→ 再分三限（少、中、老）→ 再按来人所问取象（学业、当兵、技校、疾病、早恋、厌学、交友）。[P174-175]

**R102** 行枭运则侧重枭之象立论，行他神运则侧重该十神之象（整体与分论结合）。[P175]

### 5.3 六亲转位变通

**R113** **甲→戊（父）→戊合辛→父有灾**（本书最完整的一次转位示范）：

**R116** 女命六亲变通看多寡：六木一辛 → 女多男少、阳多阴少；此处**以官为男为阳、财为女为阴**（因甲乙见辛为官，辛见甲乙为财）。辛坐未（未中乙为辛之偏财）→ 常往偏财（小媳妇）处跑 → 「找啥对象也过不好」。[P245]

### 5.4 真六亲：作者不传

**R118**（作者主张）盲派八字断六亲的秘诀在**真六亲**，不在十神六亲：

> 盲派八字的秘诀在于真六亲，而不是这个十神六亲；当然食神（疑为「十神」）六亲也有用，比如财临财位又得地，则父亲长寿，这还是很准确的。关于盲派的真六亲，这里不方便随便〔说〕，请你原谅。[P260]

→ **真六亲之法，作者明言不公开。** 本册只收十神六亲与宫位六亲两套，凡遇「十神六亲与实况不合」之例，书中一律归入真六亲，读者不可据此自造规则。[P260]

### 7.2 类象用神：无格无局时的职业取法

**R171**（作者主张，本册最实用的一条）无格无局者，可用**类象用神**断职业：

> 比肩羊刃是谋取暴利……他可能去搞保险，可能去搞传销呢，可能是诈骗，可能是经济融资呢……他不是格局用神，他是类象用神……他无格无局，说白了，他不归水利局管，也不归土地局管。[P245]

**R172** 比劫多而旺 → 财被劫，「别说没有财，就是有财也让人劫跑了」，连大运流年之财亦被劫 → 官不得用、财不得势。[P244-245]

**R173** 阳刃透伤劫 → 可从事执法行业，少时若从军，可见刑律之禄；若不从法律刑事职责 → 终生易犯刑法，有惊险之财。[P167]

**R174** 偏印偏业 → 老谋深算；比劫羊刃 → 暴利；二者并见 → 诈骗求财之象。[P245]

## 八、十神组合断法

原书在 P146–P149 以「十种生克组合」统摄全部组合断语，其后各章又逐条加注条件。以下按组合列条件与结论。

### 8.1 组合总表

| 组合 | 机制 | 主要结论 | 出处 |
|---|---|---|---|
| 印化官杀 | 官杀生印、印生身 | 以读书博功名；杀印相生功名特达 | [P146] |
| 食伤制杀 | 食伤克官杀 | 降龙伏虎、除暴安良；制不住则杀攻身 | [P146] |
| 伤官克官 | 伤官克正官 | 破规则、招灾惹祸；伤尽则贵 | [P147] |
| 财生官 | 财生官杀 | 以财取贵；身弱则财官成无底洞 | [P147] |
| 财克印 | 财克印 | 贪财坏印、迁徙、丧母、失靠山 | [P147] |
| 印制食伤 | 印克食伤 | 补血给氧；过则乏乳少食、子息有灾 | [P148] |
| 食伤生财 | 食伤生财 | 富贵自天排；无财可恃则虽巧必贫 | [P148] |

### 8.2 伤官见官

**R179** 伤官见官 → 轻则罢职，重则恶疾。[P147]

**R180** 条件分层：

- 伤重官轻 → 轻视丈夫（女命）；伤轻官重 → 招丈夫羞辱。[P147]
- 一官一重伤 → 财轻克破、退田庄。[P147]
- 官星被破尽 → 当推命入黄泉。[P147]
- 伤官临太岁（流年）→ 必招横祸于斯年。[P147]

**R181** 伤官把官星完全伤尽 → 上上大吉，「伤尽了所有的官儿，那你不就成了最大的官儿了吗」；女命伤尽官星 → 贞洁烈女，不会乱来。[P147]

**R182**（作者修正，重要）伤官见官非一律凶，须看格局真伪：

> 要按照伤官见官祸事百端说，这个八字岂不是犯法蹲监牢了？为什么他还能逍遥自在、享受富足呢？就是因为八字格局真显。[P214]

该造伤官当令司权出干，本不宜见官，然格局真、印星（卯运）出而制伤救官 → 反「贵可接云」，只是自己再做大官的机会很小，「只好靠别人家的官」。[P214]

**R183**（作者修正）枭神夺食、劫财败财，「也都可以看成是伤官见官，都是一个意思，只是在某一个命局中，泪相簿（疑为「类似」）一样罢了」。[P224]

### 8.3 财克印

**R184** 财克印 → 为钞票不要良心；为求财而背井离乡。[P147]

**R185** 财克印亦为**迁徙信号**：常有搬家、调换工作单位、购置房子车子店面等象。[P147]

**R186** 印为母、财为父 → 财克印有丧母、父母离异之象。[P147]

**R187** 印为靠山贵人 → 财克印有失去靠山贵人而罹难遭灾之象；印为福气 → 财克印多劳累、损身体，甚至丧命。[P147]

**R188** 财克印 → 无学历（壬戌运正财运，财克印）。[P237][P239]

> 数科不第，只因财破文；财多不喜读书；幼岁丧母，只因财多印死；印星被伤，失祖业，抛离故土；贪财坏印，岂是良人；印逢财而罢职；正印若逢财，官非日日来；独印逢财，定断魂归地狱；印多行财运发福；弃印就财，发福最大。[P147]

**R189** 贪财坏印 → 罢职、官非；运去财 → 反作福；再行财运 → 寿元终。[P155]

**R190** 印多行财运 → 发福；弃印就财 → 发福最大（条件相反则结论相反，见上条歌）。[P147]

### 8.4 印生劫财

**R191** 印生比劫 → 印为凭据借条，劫财为债务：印生劫财是债务，「印代表的（凭据）可能有凭据借条，劫财代表的债务就是欠着不给了」。（此为作者打麻将之喻，然义象成立：印＝文书凭证，劫＝欠而不还。）[P37]

**R192** 印绶多根不畏财，喜逢比劫 → 「福胚胎」；印星破散则官来救 → 福寿平生。[P154]

**R193** 印重比劫多 → 比劫得印生而愈旺，夺财愈烈（由 R71、R184 合成之条件，原书未另立条，此处只作提示，不作定断）。

### 8.5 劫财夺财

**R194** 财轻劫重 → 平时喜走衙门、克妻二三场、风流浪荡。[P148]

**R195** 财多逢比劫 → 家旺人殷富（与上条条件相反，结论相反）。[P148]

**R196** 比肩相叠 → 忌妒相争；比肩成局 → 当为几度新郎。[P148]

**R197** 劫财阳刃 → 离祖成家；外谦和内狠毒。[P148]

**R198** 众劫分财 → 「气数终」。[P148]

**R199** 姊妹刚强 → 乃作填房之妇。[P148]

**R200** 财神透干＋比劫同值 → 一生名利被分张；故财神忌透只宜藏。[P152]

### 8.6 枭遇食（枭夺食）

**R201** 枭食并见 → 寒必彻骨。[P148]

**R202** 枭食乏乳 → 在老人则主缺食。[P148]

**R203** 日坐枭或枭重 → 因食而疾。[P148]

**R204** 女逢枭神（重）→ 非为吉，产难惊人、病亦危。[P148]

**R205** 印多 → 老而无后；伤枭两备 → 子懦妻愚。[P148]

**R206** 食神逢枭 → 福减；须偏财救：「若无偏财来救护，命如秋草带冬霜」。[P153]

**R207** 食神逢枭遇劫 → 总成空。[P153]

### 8.7 比肩争夫

**R208** 女命五阳干见官星而无财，或见财而无官 → 争夫之命；男命反之。理据：「比者，争也。」[P156]

**R209** 女命比肩多 → 婚多、易被争夫、宜偏房小嫁。[P167]

### 8.8 合官非为贵取

**R210**（原书疏解）「合官」指官星为格局用神，而食神来合之、牵制之：

> 这里的合官，说得不也是官星为格局用神吗？用神（盲师称其为好字）看到食神这个贪欢好玩的东西来牵制它，盲师一般都会称其为：高门楼上挂彩灯，外面光滑里面空。清高可贵本为吉看，不想食神乘势来合，败坏坚实，令其内虚不诚，可见其善者可令善者不善也！[P171]

**R211** 条件：官星为格局用神＋食神来合 → 外面光滑里面空，格虚不实，不作贵取。[P171]

**R212** 对照：「重犯官星，只宜制伏」之「制」是制伏（抓捕后教育使其服气），非牵制；「制不住就服不了」。[P169-170]

### 8.9 其余六组

**R213** 印化官杀：印不宜太多，太多则懒散、少进取心、减贵气；女命官星轻 → 丈夫无大出息；官杀愈多则压力愈大、成就相应愈大。[P146]

> 众杀猖狂，一仁可化；杀印相生，功名特达；官印相生，出仕驰名；以杀化权，定显寒门贵客；印重官轻，职居卑位；印重官轻，坐堂招夫；枭印重重，生离死别之妇。[P146]

**R214** 食伤制杀：制不住则七杀随时攻身；制过头则七杀失去威风、「英雄没有用武之地」。[P146]

> 食神制杀，英雄独压万人；食神制杀，英俊文章发少年；食神制杀衣禄丰；伤官有情来合杀，金榜标名定是真；食居先，杀居后，平生衣禄福最厚。[P146]

**R215** 财生官：以财色取悦官贵、换取名位；女命以财生官杀即经济上支援丈夫，故有旺夫一说。最怕身弱担不起财官。[P147]

**R216** 印制食伤：食伤过重时以印制之为「补血给氧、补充知识」；印过重时以印制食伤则「吃不了兜着走」。[P148]

**R217** 食伤生财：八字有食伤而无财官 → 随性而为，爱好不与经济利益挂钩；食神生财之人较实际，善抓机会，容易发财。[P148]

**R218** 劫克财：以身体（卖力、卖血）、以朋友人气（合伙、传销）求财；命格不好者易起偷摸抢劫之念。[P148]

**R219** 官杀克比劫：对付官杀宜印化或食制，不宜比劫直接抵抗，「那叫以身试法，以命相争」，多数人只会成为抗暴烈士。[P149]

**R220** 食伤泄比劫：身强逢食伤一泄 → 活动多、爱说话、喜操心、常出远门；食伤克官 → 工作职务变动（官为喜则祸，官为忌则吉）。[P149]

**R221** 比劫太弱而食伤太旺 → 如患厉害腹泻，无力动弹，须走比劫运帮身才活动起来；被食伤泄弱之命主多不爱说话、不愿出头、不喜读正规书籍、常头晕。[P149]

### 8.10 组合断法的三条禁忌

**R222** 不可把两种口诀凑在一起用。作者批门人：「你把两种口诀弄到一起去理解，岂能不错？」（如把「官星一位格清高」与「合官非为贵取」硬拼）[P171]

**R223** 不可见名目便套：「不可见『印逢官生』等名目便套；四墓格局与常格不同，不可同看。」[P260]

**R224** 不可执一诀定生死：同一命可同时见两诀（既「七杀丰厚反到王前」发贵，又「五杀短命孤雁」不寿），富贵与寿元分由不同「杀数」承担。[P277]

## 九、作者立场：批《十神唠家常》

本册所据材料中，作者对一部题为《十神唠家常》的流行读物逐条批驳，凡三处，皆关系十神类象之根本，故单列。

### 9.1 批「日干为君」

引原文：「如果把八字命局比做是朝廷的话，那么日主便是皇帝。」

苍批 [P195-196]：

- 「这句话极端得错误……这就是现时社会中，无君无父，少礼失法，离辙背道的明显表现，人人想称王，个个愿为君！」
- 「人君者，上领诸天星宿，下治百姓黎民，岂日干一微可当者乎？……这是看八字的大体错误。」
- 「日干者，命局之微尘，不足道矣……要看这个八字的原局是谁当权得势了，当权得势的才是命局的灵魂，不是以一个日干来看命的。」
- 又批原文「处处离不开自己，说明完全忘记了月令和太岁」。

**R225**（作者主张）日主不代表命主本身：「日主只是门把手，月令才是这扇门的灵魂」；日主是火车，月令是铁轨，破格之字如出轨，车毁人亡。[P272-273]

### 9.2 批「七杀劫妻」

原文以「心术不正的小人（七杀）」夺妻。

苍批 [P196]：「这里类象都选错了——七杀是不会来劫取老婆的，反而是劫财。」并指原作者「把八字原局的官鬼看成是命主老婆的官鬼是错误的」。

**R226** 夺妻之星是**劫财**，不是七杀；不可把「命主之官鬼」与「妻之官鬼」混为一谈。[P196]

### 9.3 批「食神化劫」的温情喻

原文：「用食神化掉群劫争财的凶顽之气，因食神为比劫所生，就像见到自己可爱的孩子，看在孩子的份上大人不起争端。」

苍批 [P196]：「这里错误大了——我没看到抢劫犯有几个能看在孩子的份上，也没看到过土匪会怜悯孩子。我想不敢抢劫他爹，是因为他有一个做警察的儿子，或者因为他有一个像运动员那样高大的儿子吧。」

**R227** 食神制劫之真实机制是**力量压制**（儿能制父），不是情感感化。取象不可用现代人情伦理替代五行生克。[P196]
